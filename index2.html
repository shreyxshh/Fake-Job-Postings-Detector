How it works

The prediction is made on the server. This page only collects the form and shows the response.

  1. 1

    You enter the listing

    The form collects the posting text, three details and three yes-or-no signals. The job title is the only required field.

  2. 2

    The page asks the API

    Your browser sends the fields as JSON to POST /predict on your FastAPI backend, which passes them to the trained model.

  3. 3

    The model returns a probability

    The API replies with a fraud probability and a label. A posting is labelled fraudulent when the probability is above 50%.

The trained model file is never loaded in the browser, and the backend does not store what you submit.

About the model

The model is a logistic regression with balanced class weights, trained on a dataset of 17,880 job postings in which about 4.8% are labelled fraudulent.

It counts the words in the posting text, encodes the three category fields, and uses the three yes-or-no signals as they are. It does not look up the company, check links or verify anything outside the text you give it.

Read the result as an estimate. In the notebook’s test split, roughly 1 in 4 postings the model flagged were genuine, and about 1 in 6 fraudulent postings were missed. Verify the employer independently before sharing personal details.
